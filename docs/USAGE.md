# 使用教程：从零到在 QQ 里说话

> 这份教程对应 **v0.1.2**。你手上应该有一个 `dsh-qq-oneclick-v0.1.0.zip`。
> 全程不需要命令行，不需要装 git，也不需要系统里有 Node（包里已经带了）。

---

## 0. 先看清楚这事需要什么

这不是一个"装上就能聊"的软件，它是一条链子：

```
QQ客户端(NTQQ) → SnowLuma（把 QQ 变成接口）→ 本安装器装的东西 → DeepSeek Harness（大脑）
```

**四样东西缺一不可**：

| 需要什么 | 谁提供 | 你什么时候弄 |
|---|---|---|
| 官方 QQ NT 客户端 | 腾讯 | 第 1 步 |
| SnowLuma | 第三方（自己去它仓库下） | 第 1 步 |
| DeepSeek Harness（DSH） | DeepSeek | 第 1 步 |
| 本安装器 | 就是你下的这个 zip | 第 2 步 |

> ⚠️ **本安装器不下载、不代装 SnowLuma**（它的许可不允许再分发），也不代你扫码登录。
> 它负责的是中间那层"把 DSH 和 QQ 接起来"，以及装完给你一个能调的界面。

---

## 1. 先把三样东西准备好

### 1.1 官方 QQ（NTQQ）

必须用**官方 NTQQ**，不是 TIM、不是各种魔改版。装好、登录一次，确认能正常用。

### 1.2 SnowLuma

**不用自己去 GitHub 翻。** 走到向导「配置」页时，SnowLuma 那一段有个 **「下载 Windows 包」** 按钮：

- 它会去查官方最新发行版，**自动挑出唯一正确的那一个**（`win-x64.zip` 完整版，41 MB）——
  Releases 页同时挂着 linux-arm64、linux-x64、lite 等 6 个包，很容易点错；
- 点一下，浏览器直接开始下载。

下载完自己做三步（SnowLuma 没有安装程序，解压就是"装好"）：

1. 右键解压到 `D:\SnowLuma`（或任意目录），**别在压缩包里直接双击**；
2. 双击里面的 `launcher.bat` → **扫码登录你的 QQ**（建议小号）；
3. 回到向导点 **「我解压好了，选目录」**，选到有 `index.mjs` 的那一层。

选完路径自动写进配置，你不用再手填。

> 为什么下载/解压/启动不替你做：SnowLuma **EULA §5.4** 把「并入第三方安装包」「通过自动化脚本部署」
> 列为**需事先书面授权**的行为。我们只把正确的链接递到你手上。
>
> 判断解压对不对：那一层目录里能看到 `index.mjs`、`release.json`、`node.exe`。
> 如果向导已经自动找到了（它扫配置记录的路径、安装目录旁、用户目录、各盘根），这步可跳过。

登录后，在 SnowLuma 的设置里打开 OneBot v11，记下三个值：

| 值 | 一般长什么样 | 填到哪 |
|---|---|---|
| HTTP 地址 | `http://127.0.0.1:3000` | 向导「配置」页 |
| WS 地址 | `ws://127.0.0.1:3001` | 向导「配置」页 |
| AccessToken | 一串随机字符 | 向导「配置」页 |

> 端口不一定就是 3000/3001，**以 SnowLuma 里实际显示的为准**。
> HTTP 和 WS 可能是两个不同的 token，别想当然。

### 1.3 DeepSeek Harness（DSH）

按官方方式装好，能正常打开它的 Web 界面。

> 没有 DSH 也能把程序装上，但**没有人会回你消息**——因为"说什么"是 DSH 在决定。

## 2. 装安装器

1. 把 `dsh-qq-oneclick-v0.1.0.zip` **解压到一个你不会随手删的目录**（比如 `D:\Tools\dsh-qq-oneclick`）；
2. 双击 **`start.bat`**；
3. 稍等几秒，浏览器会自动打开安装向导（地址是 `http://127.0.0.1:3210`）。

> 端口被占用时它会自动往后找（3210 → 3240），以命令行窗口里显示的地址为准。
> 这个黑窗口**装的过程中别关**，装完可以关。

---

## 3. 向导里怎么点（六屏）

### 第 1 屏 · 环境检测

它真的会去探：系统、Node、DSH、3000/3001/3100 端口、目标目录能不能写、能不能连上 GitHub。

| 看到什么 | 怎么办 |
|---|---|
| 全绿 | 直接下一步 |
| 黄项（注意） | 一般能继续。比如"3100 被占用"——如果你之前已经装过一套，这是正常的 |
| 红项（阻塞） | 按它给的「→ 怎么修」做。修不了也能继续，但出问题先回来看这里 |

### 第 2 屏 · 出处与许可

这里列出**每一个**会用到的第三方组件：作者、仓库、许可证、我们改了什么。

滚到底，勾上「我已阅读…」才能点下一步。这不是走过场——你从这里能看出谁的东西被用了、各自什么条款。

### 第 3 屏 · 安装位置

默认 `C:\Users\你\AppData\Local\DSHQQ`。可以改，但**建议用默认**。

记住一句话：**程序装这里，记忆不在这里**。角色、记忆、B站凭据固定在 `C:\Users\你\.dsh\` 下，换目录不会丢。

### 第 4 屏 · 功能选择

三个套餐按钮，选一个就行：

| 套餐 | 适合谁 | 大概包含 |
|---|---|---|
| **最小** | 先跑通，别管花活 | 收发消息、引用、表情、图片理解、补历史、记忆卡 |
| **推荐** ⭐ | 大多数人 | 最小 + 长消息转图 + 语音条发送 + 多角色 + 黑话 + 额度 |
| **全量** | 什么都想试 | 推荐 + 语音转文字 + 主动找人 + B站 + 桌宠 |

不确定就选**推荐**。每一项鼠标悬停都有说明，勾了不需要的也能随时在设置里关。

### 第 5 屏 · 配置

只填四个地方，其余几百个键都有默认值：

| 字段 | 填什么 | 不填会怎样 |
|---|---|---|
| **你的 QQ 号** | 你自己的号 | 管理指令、审批全部失效 |
| **允许的群** | 群号，逗号分隔 | **留空 = 谁都不理**（不是全放行） |
| **允许的私聊** | QQ 号，逗号分隔 | 同上 |
| **SnowLuma 三个值** | 第 1.2 步记下的 | 连不上 QQ，控制台显示未连接 |

> **白名单留空不是"全开"，是"全关"。** 这是故意的安全默认。
> 想先自测，就把你自己的号填进「允许的私聊」。

控制台令牌留空即可，装的时候自动生成。

### 第 6 屏 · 确认安装

看清楚要装什么，点「开始安装」。它会依次：

```
预检 → 下载 SurfCore v0.8.0（7 MB，校验 sha256）→ 解包（579 个文件）
     → 准备 npm（系统没有就自己下一份）→ npm ci（128 个包）
     → 写配置 → 注册进 DSH → 自检 6 项
```

- 装依赖那一步最慢（一两分钟），**别关窗口**；
- 中途失败会**自动回滚**，不会留半个安装；
- 装完会给你一张自检表，红项照着后面的「→」修。

**关于「注册进 DSH」**：它会往你的 DSH 里写 3 个工具服务 + 1 个插件包，这样 DSH 设置里才会出现 SurfCore。
如果你机器上**已经装了另一套** SurfCore（比如你自己开发用的），它会**停下来问你**，不会抢走——要改指向得勾「强制改指向」。

## 4. 让它在 QQ 里真的说话

装完只是"装好了"，还差三步：

### 4.1 重启 DSH

关掉 DSH 再打开。这样新注册的工具和插件才会加载。

在 DSH 的 **设置** 里应该能看到 **SurfCore** 这一项，说明注册成功。

### 4.2 启动桥接

双击 **`settings.bat`**（或从安装完成页点「打开设置中心」），在「概览」里点 **启动桥接**。

看到状态变成「本安装器的桥接在跑」，就对了。

> 如果显示「3100 上有别的 SurfCore 在跑」——说明你机器上还有另一套在用，这里**不会去动它**。
> 两套同时跑会抢同一个群的消息，只能留一套。

### 4.3 在群里 @ 它一次

```
@你的机器人 你好
```

正常的话：QQ 里收到回复，同时 DSH 里出现一个对应的会话。

**三件事同时成立才算通**：QQ 有消息进 → DSH 有会话 → 回复回到 QQ。

> 第一次没反应，先看设置中心「诊断 → 看最近日志」，别急着重装。

## 5. 日常怎么调（设置中心）

双击 **`settings.bat`**，不需要打开 DSH：

| 区块 | 能干什么 |
|---|---|
| **概览** | 看版本、目录、桥接状态、DSH 注册指向；启动/停止桥接 |
| **白名单与主人** | 加群、加人、换主人 QQ |
| **语音** | 允许发语音条、是否现场合成、走本地还是云端 |
| **诊断** | 跑一次自检 6 项、看桥接日志尾巴 |

两条规矩（写在这里是因为容易踩）：

1. **改完白名单要重启桥接**才完全生效——界面会提示，别改完就等消息；
2. **写配置一律先备份**到 `data\config.bak\`，写坏了能捞回来。

## 6. 语音转文字（STT）怎么用

这是本安装器**自己加的**能力（上游没有），装在向导第 4 屏勾「语音转文字（STT）」。

- 额外占 **82 MB**（引擎 9 MB + 模型 74 MB）；
- **完全本地跑，不联网、不上传音频**；
- 装完 DSH 里多两个工具：`stt_status`（看装没装）、`stt_transcribe`（把音频转文字）。

**一条必须知道的限制**：whisper 能解 `wav / mp3 / flac / ogg`，
但 **QQ 语音多是 silk/amr**，这两种解不了——得先转成 wav 或 mp3 再喂进去。
报错时会直接把这句话告诉你。

## 7. 常见问题

| 现象 | 最可能的原因 | 怎么处理 |
|---|---|---|
| 向导打不开 | 端口被占 / 黑窗口关了 | 看命令行窗口里显示的地址；重新双击 `start.bat` |
| 装完 QQ 里 @ 它没反应 | 白名单没加这个群 / 桥接没启动 / SnowLuma 没登录 | 设置中心看状态 → 白名单加群 → 启动桥接 → 确认 SnowLuma 在线 |
| 收得到消息但 DSH 没反应 | DSH 没重启 / 注册没成功 | 重启 DSH；设置中心看「DSH 注册」 |
| 控制台 401 | 没带令牌 | 用 `http://127.0.0.1:3100/?token=<控制台令牌>` |
| 报 426 | HTTP 地址填成了 WS 端口 | 检查「SnowLuma HTTP 地址」是不是 `http://...:3000` 这种 |
| 装了但 DSH 里找不到 SurfCore | bundle 没加载 | 重启 DSH；仍没有就重跑一次安装（走修复，不会丢配置） |
| 日志里一大堆「未连接」 | SnowLuma 没起 / token 不对 | 先开 SnowLuma 并登录，再核对 token |
| 想换安装位置 | —— | 重装到新目录即可，配置会跟着走；旧目录手动删 |

## 8. 卸载

双击 **`uninstall.bat`**。默认**只删程序，留配置和记忆**。

想要更彻底，在命令行里加参数（目录换成你的安装目录）：

```bat
runtime\node\node.exe installer\uninstall.mjs --target "C:\Users\你\AppData\Local\DSHQQ" --purge
:: 连记忆一起删（角色/记忆/B站凭据），要再加 --yes
runtime\node\node.exe installer\uninstall.mjs --target "C:\Users\你\AppData\Local\DSHQQ" --purge-all --yes
```

卸载会**先摘掉 DSH 里的注册**（并备份 `cordis.patch.yml`），再删文件。

## 9. 它不做什么（先知道，少踩坑）

- **不打包别人的东西**：SurfCore 装时从上游拉，SnowLuma 你自己装，模型你自己下；
- **不代你登录**：QQ 扫码、B站扫码都由你本人完成；
- **不放行所有人**：默认白名单为空 = 谁都不理；
- **没有遥测**：不上报任何数据；
- **不保证账号安全**：QQ 对自动化有风控，用小号、控频率、别群发。
